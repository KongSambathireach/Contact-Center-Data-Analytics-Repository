# Contact-Center-Data-Analytics-Repository
A complete contact center analytics solution covering data preparation, KPI calculation, workforce performance, operational analysis, and interactive reporting using Excel, Power Query, Power Pivot, SQL, and Power BI.

## Objectives
The goal of this project is to analyze the performance of a call center company
#### **Requirements** 

To run and reproduce this project, the following tools are required: 

- **Excel**: Used for initial data cleaning, pivot tables, and visualization. 

- **Power BI**: Used for advanced visualizations, reporting, and dashboard creation.
